## Assumptions

- Proposed purpose, using the existing [README](README.md) wording:
  "Conquistador turns product context and performance evidence into finished,
  channel-native marketing work."
- Proposed audience: operators who use coding agents for product marketing
  and growth. Inferred from the README's complete-plugin and single-skill uses.
- Proposed main outcome: a usable deliverable with one clear next action.
  Inferred from the completion contract in
  [the default skill](skills/conquistador/SKILL.md).
- Proposed principles: use the customer's brand, support claims with evidence,
  and retain explicit approval for consequential actions. Inferred from the
  default skill and [safety standard](skills/conquistador/standards/safety.md).
- Proposed limits: the package supplies instructions, while the host supplies
  tools, permissions, identity, and memory. The README excludes the parent
  monorepo's desktop and Rust experiments from this package.
- Proposed signal: discovered skills and their versions match the package
  source. The README describes discovery and manual version checks, but
  gives no adoption target.
